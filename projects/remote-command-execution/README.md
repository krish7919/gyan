# remote-command-execution
A template service to create something like Go playground

## Prerequisites

1. Install Go 1.26.
2. Install [`asdf`](https://asdf-vm.com/guide/getting-started.html#install-asdf)
   and all the plugin versions mentioned in `.tools-version` file. Ensure that
   `asdf` is configured to include plugins in the `PATH`:

    ```bash
    # ASDF Setup
    export PATH="${ASDF_DATA_DIR:-$HOME/.asdf}/shims:$PATH"
    . <(asdf completion bash)
    ```
